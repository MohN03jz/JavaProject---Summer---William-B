# JavaProject---Summer---
Description- 
Submission of a game library for our Java course that aims to create a complete sum of owned games across all platforms the user owns
- rather than individualized libraries on certain applications like Steam.

Features-
Features of this application include CRUD operations regarding managing the list, viewing details of selected games, and filtering selections by recent additions
- or favorited submissions.

Instructions-
1. Open IntelliJ IDEA and choose File → Open, then select the javafx-app folder (the one containing pom.xml).
2. Allow IntelliJ to import the Maven project and download dependencies.
3. Go to File → Project Structure → Project and set the Project SDK to an installed JDK version 17 or newer.
4. Open the Maven tool window on the right edge of the IDE, then expand javafx-app → Plugins → javafx.
5. Double-click the run goal to build and launch the application.
